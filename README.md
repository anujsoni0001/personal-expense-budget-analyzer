# Personal-expense-budget-analyzer
Excel-based expense tracking, budgeting, variance analysis, and financial dashboard.

## Project Overview
The Personal Expense & Budget Analyzer is an Excel-based financial analysis project designed to track income and expenses, compare actual spending against category budgets, calculate savings, and visualize financial performance through a dashboard.

## Project Objectives
- Track income and expenses in a structured transaction table.
- Compare actual expenses with planned category budgets.
- Calculate total income, expenses, net savings, and savings rate.
- Identify the highest-spending category and largest expense.
- Present key financial metrics using charts and a dashboard.

## Workbook Structure
1. **Transactions:** Records dates, transaction types, categories, descriptions, payment modes, and amounts.
2. **Budget Vs Actual:** Compares budgeted and actual spending, calculates variance, and highlights over-budget categories.
3. **Analysis:** Summarizes important financial metrics.
4. **Dashboard:** Displays key performance indicators and charts for expense distribution and budget-versus-actual comparison.

## Tools and Skills
- Microsoft Excel
- Excel formulas and financial calculations
- Data validation and structured tables
- Conditional formatting
- Budgeting and variance analysis
- Dashboard and chart creation

## Key Learning Outcomes
This project provided practical experience in organizing financial data, tracking expenses, comparing actual spending with budgets, calculating savings, and communicating results through visualizations.

## Limitations and Future Improvements
The workbook uses illustrative sample transactions and a predefined monthly budget. Future improvements could include multi-month analysis, automated category summaries, and additional financial insights.

## Data Note
All transactions and figures are illustrative sample data created to demonstrate the workbook's functionality. They should not be interpreted as actual personal financial records.
